# Nostra-E-commerce-Website
Nostra is a responsive e-commerce website created as a front-end development project using HTML, CSS, and JavaScript.  The project includes multiple pages and interactive features designed to provide a simple and user-friendly shopping experience.

Features
 Responsive Home page
 Image slider with previous and next navigation
 New Arrivals section
 Most Wanted products section
 Wishlist interaction
 Product search functionality
 Product filtering by:
Occasion
Color
 Responsive navigation menu for mobile devices
 Newsletter subscription section
 Contact Us form
 Multiple page navigation
 Responsive layout for different screen sizes
 Technologies Used
HTML5
CSS3
JavaScript
Font Awesome
Tailwind CSS
 Pages
 Home

The home page contains the promotional banner, navigation bar, image slider, brands section, customer experience section, New Arrivals, Most Wanted products, newsletter section and footer.

 Collections

The Collections page allows users to search products and filter them based on occasion and color.

Contact Us

The Contact page contains a contact form where users can enter their name, email and message.

Product Filtering

The Collections page uses JavaScript to filter products based on the selected checkbox options and search input.

Users can filter products by:

Summer
Party
Beach
Red
Blue
White
Green
 Responsive Design

The website is designed to work across different screen sizes.

On smaller screens:

Desktop navigation links are hidden.
A hamburger menu is displayed.
A side navigation menu can be opened.
Product layouts adjust according to screen size.
